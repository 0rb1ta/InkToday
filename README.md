# InkToday

Неофициальный клиент [author.today](https://author.today) для электронных книг PocketBook.
InkToday не является официальным продуктом author.today и не связан с порталом.
Использование публичного API согласовано с администрацией author.today (октябрь 2026).

## Что умеет

- вход в аккаунт author.today, включая подтверждение кодом из письма;
- ваша библиотека с сайта и полки («Читаю», «Отложено», «Прочитано»…);
- подборки главной страницы и карточки книг, циклы, похожие книги;
- каталог с фильтрами: жанр и поджанр, сортировка, статус, доступ, «можно скачать»;
- поиск в каталоге одной строкой: по названию, автору и тегу; все книги автора; теги в карточке книги открывают каталог с этим тегом;
- скачивание книг (EPUB или FB2), если автор разрешил скачивание, и открытие в родной читалке PocketBook;
- покупка — только на сайте, через QR-код на телефоне;
- место чтения: в карточке видно, где вы остановились в читалке и на сайте; по желанию место из читалки уходит на сайт, а «Читать» предлагает открыть книгу там, где вы читали на телефоне (см. ниже).

Скачанные книги — только для личного чтения. Права на них принадлежат авторам; распространять файлы нельзя.

Книги, у которых автор закрыл скачивание, приложение не скачивает и не сохраняет: они отмечены «На сайте». Если автор открыл скачивание только своим подписчикам, книга отмечена «Подписчикам»: подписаться можно на сайте по QR-коду, после этого книга скачивается как обычно.

Поиск по названию и автору работает через страницу поиска сайта author.today (в API его нет), поэтому может временно перестать работать, если сайт поменяет вёрстку. Поиск по тегу и каталог работают через API.

## Установка

Проверено на PocketBook 970 (InkPad Lite), прошивка 6.8.

На других моделях с прошивкой 6.x приложение, скорее всего, запустится, но это не проверено. Попробовали на своей читалке — напишите в [Issues](https://github.com/0rb1ta/InkToday/issues), работает ли: модель, версия прошивки и, если что-то не так, файл `system/inktoday/log.txt`. С прошивкой 5.x и старше не работает.

1. Подключите читалку к компьютеру по USB.
2. Скопируйте содержимое архива релиза в корень внутренней памяти: `applications/InkToday.app`, `applications/icons/` и папку `system/inktoday/`.
3. Отключите читалку и запустите приложение из раздела «Приложения».

Удаление: удалите `applications/InkToday.app`, файлы `applications/icons/inktoday*.bmp` и папку `system/inktoday/`. Если иконка была добавлена в меню, сначала уберите её (см. ниже). Скачанные книги лежат в `Books/author.today/` — их можно оставить.

### Вход

Вход — логином (почтой) и паролем от author.today; при первом входе сайт пришлёт код на почту. Вход через ВКонтакте, Яндекс и другие сервисы пока не поддерживается. Без входа можно смотреть каталог и карточки, но скачивать нельзя.

### Место чтения

Две настройки в разделе «Скачивание» (по умолчанию выключены):

- **«Отправлять место чтения на сайт».** Когда вы возвращаетесь из читалки в InkToday или запускаете его, место из читалки уходит на сайт — его увидят приложения author.today на телефоне. Отправляется только более свежее место: прочитанное на телефоне позже не затирается.
- **«Предлагать место с сайта при «Читать»».** Если на сайте вы читали позже, перед открытием книги приложение спросит, открыть ли её там. Прошивка открывает книгу только по номеру страницы, поэтому место — примерное (±1 страница).

Сама читалка с сайтом не связана: если не запускать InkToday, место никуда не уходит.

### Иконка в меню «Приложения»

Без настройки приложение видно в меню под именем файла, без своей иконки. Иконку прошивка 6.x берёт из файла `system/config/desktop/view.json`. Добавить её можно двумя способами.

**Из приложения.** «Настройки» → «Обслуживание» → «Иконка в меню приложений». Приложение сохранит копию файла (`view.json.inktoday-backup`) и допишет свою запись. Там же иконку можно убрать. После этого перезагрузите читалку.

**Вручную.** Сделайте копию `system/config/desktop/view.json`, затем откройте его в текстовом редакторе:

1. В раздел `"applications"` добавьте запись:

   ```json
   "U_InkToday": {
       "path": "/mnt/ext1/applications/InkToday.app",
       "title": "InkToday",
       "icon": "/mnt/ext1/applications/icons/inktoday.bmp",
       "focused_icon": "/mnt/ext1/applications/icons/inktoday_f.bmp"
   },
   ```

2. В разделе `"view"` → `"groups"` допишите `"U_InkToday"` в список `"apps"` группы `"@General"`.
3. Сохраните файл, отключите читалку от компьютера и перезагрузите её.

Если после правки меню показывает ошибку, верните сохранённую копию файла. Прошивка иногда перезаписывает `view.json` (например, при обновлении) — тогда иконку нужно добавить заново.

### Обновления

При запуске приложение проверяет, есть ли на GitHub новый релиз. Если есть — в шапке главной появляется значок со стрелкой; по нажатию открывается QR-код со страницей релиза. Новую версию копируют так же, поверх старых файлов: вход и скачанные книги сохранятся.

## Известные ограничения

- Проверено только на PocketBook 970 с прошивкой 6.8; на других моделях может не работать.
- Прошивка сама выключает Wi-Fi; приложение включает его перед запросами, иногда это занимает несколько секунд.
- У API author.today есть лимиты запросов: при большой библиотеке первые минуты после синхронизации кнопки на плитках обновляются не сразу.
- Новые книги появляются в библиотеке PocketBook после её обновления (пересканирования).
- Обновлённая книга (новые главы) для читалки — новый файл: место чтения в ней начинается сначала.

## Сборка

Нужен PocketBook SDK B288 6.8 (`github.com/pocketbook/SDK_6.3.0`, релиз 6.8).

```bash

```
